# 라이트 안내판

Android 8.0 이상용. 앱 아이콘을 누르면 마지막으로 저장한 안내판을 전체 화면으로 표시합니다. 기본 문구는 “라이트를 켜시오”입니다.

오른쪽 아래 톱니바퀴에서 문구와 글자 크기를 조절합니다. 글자 또는 배경 색상을 선택하고, 아래 무지개 막대에서 색조를, 위 사각형에서 채도와 밝기를 드래그해 바꿉니다. “저장하고 표시”를 누르면 앱을 다시 열어도 그대로 표시됩니다.

인터넷 연결이나 별도 권한이 필요 없습니다. 안내판을 표시하는 동안 화면이 켜져 있습니다. 조작은 정차 중에 하거나 동승자에게 맡겨주세요.

소스 빌드: Android SDK 36, Build Tools 36.1.0, JDK 환경에서 `./build.sh`를 실행합니다.

## 1.1.0 — 한 줄 흐르기

설정에서 **한 줄 흐르기**를 켜면 화면 높이에 맞춰 큰 글자를 한 줄로 표시합니다. 문구가 너비를 넘으면 오른쪽에서 왼쪽으로 반복해서 흐르고, 모두 들어가면 가운데 고정됩니다. 끄면 기존 자동 줄바꿈 표시로 돌아갑니다. 옵션은 문구 및 색상과 함께 저장됩니다.

Android 17(API 37) 에뮬레이터에서 기존 APK 위 업데이트, 가로 회전, 긴 문구 흐르기와 짧은 문구 고정, 재실행 시 옵션 복원을 확인했습니다. Galaxy One UI 9.0 실기기는 테스트하지 않았습니다.
